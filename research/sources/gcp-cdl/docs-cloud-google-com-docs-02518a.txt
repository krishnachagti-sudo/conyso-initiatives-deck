# {#error-reporting-documentation} Error Reporting documentation

 Read product documentation

Error Reporting aggregates and displays errors produced in your running cloud
 services. Using the centralized error management interface, you can find your application's top or
 new errors so that you can fix the root causes faster.

You can report errors from your application by sending them directly to Cloud Logging with
 proper formatting or by calling an
 Error Reporting API endpoint that sends them
 for you. The setup process depends on your platform; for instructions, see
 Setup guides.

To report errors from Android and iOS client applications, we recommend setting
up Firebase Crashlytics.
