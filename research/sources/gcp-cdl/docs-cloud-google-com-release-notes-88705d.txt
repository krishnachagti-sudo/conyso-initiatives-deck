# 
 GKE Enterprise release notes

 Stay organized with collections

 Save and categorize content based on your preferences.

The features
that were part of GKE Enterprise have become part of the
standard
Google Kubernetes Engine (GKE) offering,
or are products or features that you can
use in addition to GKE.
GKE is a single offering, without different editions or tiers.

For details about specific features, see the following release notes:

- For details about features that had been part of
GKE Enterprise, see this
release note.

- For the change to billing for metrics, see this
release note.

- GKE clusters no longer have a tier, see this
release note.

This GKE Enterprise release notes page is an archive of past updates to
GKE Enterprise. This page includes the following:

- Links to the release notes of products that are related to the former
GKE Enterprise offering.

- An archive of the release notes of the monthly component releases for
GKE Enterprise from December 14, 2022 and earlier.

 You can see the latest product updates for all of Google Cloud on the

 Google Cloud page, browse and filter all release notes in the
 Google Cloud console,
 or programmatically access release notes in
 BigQuery.

 To get the latest product updates delivered to you, add the URL of this page to your
 feed
 reader, or add the
 feed URL directly.
