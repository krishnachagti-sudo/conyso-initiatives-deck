 What is Gemini Notebook Enterprise?

 Stay organized with collections

 Save and categorize content based on your preferences.

Gemini Notebook Enterprise is a highly compliant, enterprise-ready
version of Gemini Notebook.

Gemini Notebook is an AI-powered research and writing tool that helps you
summarize and extract information across dense and complex sources. You do
this by adding data sources, such as PDFs, Google Docs, Google Slides,
and website URLs, to build a notebook. The AI grounds its responses in
these documents.

The base functionality lets you add these sources and interact with the
content to query, chat, or generate summaries.

While popular for personal use, the personal Gemini Notebook product lacks
the compliance and administrative features necessary for enterprise
environments.
Gemini Notebook Enterprise shares key features with Gemini Notebook but is
fortified with enterprise-grade security and compliance.

Note: Gemini Notebook Enterprise is a Generative AI Service subject to the
applicable terms of the agreement under which you access Google Cloud services.
## Enterprise grade for notebooks
 {#data-security}

Gemini Notebook Enterprise runs in a Cloud-compliant environment. Your data
is always within your Google Cloud project and can't be shared externally.

Documents uploaded to a notebook within Gemini Notebook Enterprise are
ingested into the Google Cloud environment and are subject to Google Cloud Terms
of Service. This also applies to documents that have been uploaded to a notebook
from Google Drive.

## Limitations on Microsoft Excel Workbook documents
 {#limitations}

Microsoft Excel Workbook documents uploaded to a Gemini Notebook Enterprise
notebook have the following limitations:

Within the general source size limits, Gemini Notebook Enterprise can
process about 150,000 active cells in a single sheet. If your data is
organized compactly, you might be able to upload a document with sheets
containing a larger number of active cells.

If a document contains multiple sheets, each sheet is processed separately.

A single document must be less than 500 MB or 500,000 words. This is the
general source size limits; see Usage limits.

When processing XLSX files, Gemini Notebook Enterprise converts the
content, including table structures and formatting, into an intermediate
format to preserve the layout for analysis. This conversion process adds
characters to represent the structure (for example, cell boundaries and
rows). These additional characters are included in the total word count.
As a result, an XLSX file with a visible word count less than 500,000
can still exceed the limit because of these added characters. For files
with complex formatting or many cells, you might see a larger
difference between the apparent word count and the system's calculated
word count.

## Separate administrator and user interfaces
 {#separate_administrator_and_user_interfaces}

There are two interfaces for Gemini Notebook Enterprise:

Admin interface: Administrators use the
project's Google Cloud console UI to enable the Gemini Notebook capability and set up
users authentication and authorization. Users with the Cloud NotebookLM
Owner role can access the admin interface.

User interface: Your end users create and manage their notebooks through
a UI that looks and behaves very much like the personal Gemini Notebook UI. The
URL for the interface is unique for each project and must be
distributed to users by the administrator.

## User roles
 {#user_roles}

There are five Identity and Access Management (IAM) roles predefined for
Gemini Notebook Enterprise:

Two roles are related to accessing Gemini Notebook Enterprise:

Cloud NotebookLM Admin: Users with this role can configure identity
settings, give users in a project access to Gemini Notebook Enterprise,
and receive the URL for the user interface for sharing with end users.

Note: Users with this role don't experience Guidebooks as chat-only because
they have full access to all notebooks.

Cloud NotebookLM User: Users with this role can sign in to the
user interface and create notebooks. Users must be granted this role in
order to access Gemini Notebook Enterprise.

The remaining three roles are the Cloud NotebookLM Notebook roles (Owner,
Editor, and Viewer). Don't assign these roles through the admin interface. These
roles get automatically assigned through the user interface, for example, when a
user creates a notebook or shares a notebook with another user.

## About data access, storage, and lifecycle
 {#about_data_access_storage_and_lifecycle}

When your users add source data to a notebook, the data is stored in your
project in the US or EU multi-region. Only Gemini Notebook Enterprise can
access the data; that is, the data can't be accessed through any other
Google Cloud service (such as Cloud Storage).

When your users delete a notebook, the data is deleted along with the notebook.
Similarly, when you delete the project, all the data is deleted.

## Searching for notebooks through Gemini Enterprise
 {#search}

You can enable Gemini Notebook Enterprise as a data source in
Gemini Enterprise. This lets your users use
Gemini Enterprise to search for their notebooks by title.

For more information about this Public Preview feature, see Enable
Gemini Notebook Enterprise as a search source.

## Gemini Notebook Enterprise availability
 {#notebooklm-availability}

You can purchase Gemini Notebook Enterprise as a standalone product or as
part of Gemini Enterprise.

Gemini Notebook Enterprise and Gemini Enterprise
