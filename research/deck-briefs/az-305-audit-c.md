# az-305 audit C: topics 10–13

Scope: decks/az-305/notes/10-compute.json to 13-networking.json. That is 407 cards (92 + 108 + 77 + 130), and none of them are pool cards. I checked every card against its `evidence` first. Where a claim went beyond the evidence, I grepped research/sources/az-305/. The sources I used were: the compute decision tree, Spot VMs, managed disk types, App Service plans, Functions hosting options, the Container Instances and Batch overviews, asynchronous messaging options, the Service Bus overview and the Storage-versus-Service Bus comparison, the event-driven architecture style, API Management key concepts, cloud migration strategies, the Data Box, storage migration and assessment calculation pages, the Firewall, Load Balancer and Accelerated Networking overviews, and the load-balancing options.

Tier B text comes from the MicrosoftDocs GitHub repositories (CONTENT-POLICY.md §3, tier B). Three pages are tier C learn.microsoft.com with a null manifest path: the Azure Managed Redis overview, the Azure Cache for Redis overview and the DMS overview. I fetched each one once to check facts, with a generic User-Agent and no personal details, and did not save them to the repository. All their claims are supported, including:
- "based on the Redis Enterprise software";
- the tier ratios (8:1, 4:1, 2:1);
- Flash Optimized being the tier that "stores data both in memory and on disk";
- "retirement timeline for all SKUs … moving … to Azure Managed Redis as soon as you can";
- DMS: "Azure SQL Database - Offline migration" only, and online migration to SQL Managed Instance and to SQL Server on Azure VMs.

I also fetched one tier B page from raw.githubusercontent.com, service-bus-premium-messaging.md (MicrosoftDocs azure-docs). I needed it to settle the Service Bus message size. The comparison table says "256 KB, 1 MB, or 100 MB … Depends on the service tier". The tier page says Premium is "up to 100 MB" and Standard "up to 256 KB", and 1 MB is Premium's limit "for SBMP and HTTP protocols". Where the docs disagree, the tier page wins. No card in topics 10–13 relies on a training-unit figure that the docs contradict.

Every one of the 59 scenario cards in topics 11–13 had its key at A (topic 10 varies). A learner could score well without reading, so I logged this as minor, one line per card. Of the 59 cards, 39 are reordered: the key moves to B or C, and the letters in the back and choicesExplained change to match. The other 20 stay at A. I left the option wording alone.
