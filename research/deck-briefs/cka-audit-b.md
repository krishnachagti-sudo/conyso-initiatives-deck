**`kubectl autoscale --cpu` on v1.35: settled.** The cached walkthrough (v1.37 docs) uses `--cpu=50%`, and its footer records "fix: replace deprecated argument `--cpu-percent` with `--cpu`". The versioned kubectl reference pages settle the version. v1.35 and v1.34 both give the usage `kubectl autoscale (-f FILENAME | TYPE NAME | TYPE/NAME) [--min=MINPODS] --max=MAXPODS [--cpu=CPU] [--memory=MEMORY]` and the example `kubectl autoscale rc foo --max=5 --cpu=80%`. v1.33 lists only `--cpu-percent int32`. So `--cpu=70%` works on kubectl v1.35 (https://v1-35.docs.kubernetes.io/docs/reference/kubectl/generated/kubectl_autoscale/, fetched 2026-09-25 with a generic User-Agent and not added to the cache).
