# GitHub Foundations: notes for every writer (read after DIGEST.md)

- **Slug:** `github-foundations`. **Family prefix:** `ghf` (card ids `ghf.<topic-slug>.<card-slug>`, concept ids `ghf.<concept-slug>`). Use the concept ids in `github-foundations-concepts.json`; add new ones only when a card needs them.
- **Builds on:** nothing. Every term gets its primer.
- **Sources, their tiers and licence labels.** The label must match src/licences.json for the host. Tier A or B: "B · <licence>", with evidence. Tier C: "C · facts only, in our own words", with no evidence.
  - learn.microsoft.com → tier C ("© Microsoft 2026" (page footer))
  - github.com → tier B ("Creative Commons Attribution 4.0 - for documentation and content in the assets,)
  - docs.github.com → tier B ("Creative Commons Attribution 4.0 - for documentation and content in the assets,)
  - brand.github.com → tier C ("© 2026 GitHub, Inc. All rights reserved." and "No adaptation or use of any kind)
  - innersourcecommons.org → tier B ("The site is licensed under a CC-BY-SA license unless otherwise marked.")
- **Evidence is required.** The texts are in `research/sources/github-foundations/`; the slice prints a passage under each concept.
- **Volatile facts:** `volatile: true`, `validAsOf: "2026-09-25 · GitHub Docs as of that date"`.
- **Scenarios:** your own. Never reuse a source's worked examples or exercises.
- **Deck notice:** already in deck.json.
