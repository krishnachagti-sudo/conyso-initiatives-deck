# gcp-pca audit, part d (topics 13–16)

Cards checked: 296 (13-security-controls 94, 14-compliance 40, 15-delivery-and-tooling 86, 16-observability-and-operations 76). Sources: research/sources/gcp-pca/ (docs.cloud.google.com pages, tier B per CONTENT-POLICY.md §3). The tier C pages had no cached text, so I read them live with a generic User-Agent: the HIPAA, COPPA, SOC 2 and Compliance Reports Manager pages, plus the Cymbal Retail and EHR Healthcare case studies to check that no scenario reuses theirs. Patches: research/deck-briefs/gcp-pca-fixes-d.jsonl (7 lines; `apply-fixes --dry` applies all 7 and names no card that breaks a rule).

What checked clean:
- Security controls. The Cloud KMS, CMEK, Autokey, Cloud HSM and Cloud EKM cards match the pages. The page confirms that Autokey uses the multi-tenant HSM protection level. VPC Service Controls (perimeter, ingress and egress, access levels), Security Command Center (its threat detection names cryptocurrency miners; the Enterprise tier shuts down on 21 May 2027) and Secret Manager against Cloud KMS also match. The audit-log cards are right: the source says Policy Denied logs "can't" be disabled, so the which-log-iam-change reasoning holds.
- Compliance. The tier C cards stay within their pages: HIPAA (1996, the BAA, "not subject to modification", all regions), COPPA (1998, under 13, schools' parental consent), SOC 2 (Trust Services Criteria, independent auditors, "only issues SOC 2 Type II") and Compliance Reports Manager ("at no additional cost"). No scenario reuses a case study's scenario.
- Delivery and tooling. The volatile cards match their pages: gsutil leaves the CLI package after March 2027, the emulator groups, the Preview release level and Infrastructure Manager's Cloud Build job. The canary-skip explanation matches the "Advance Rollout" text.
- Observability and operations. The SLO maximum of 99.9%, the error-budget arithmetic, windows-based SLOs for percentile metrics, the sink destinations and the P1–P4 support priorities are all right.
- Answer letters. All 35 lettered scenarios in topics 13–14 name exactly the three wrong options, and the back's letter matches the correct choice. The 45 scenarios in topics 15–16 name the wrong options in words and cover each one.
