# prometheus-pca audit: topics 2 to 6

Scope: 401 cards in `decks/prometheus-pca/notes/02-…06-*.json` (no pool cards): 92 fundamentals, 85 PromQL, 75 aggregation and histograms, 67 instrumentation, 82 alerting. Checked against the saved sources in `prometheus-pca-sources.json`. Every PromQL expression, function name and argument order was checked against the Functions and Operators pages (predict_linear, histogram_quantile, histogram_fraction, label_replace, label_join, count_values, topk, quantile, absent_over_time and the rest are right). Defaults checked: scrape_interval 1m, scrape_timeout 10s, evaluation_interval 1m, metrics_path /metrics, lookback 5m, retention 15d, group_wait 30s, group_interval 5m, repeat_interval 4h, resolve_timeout 5m, subquery resolution; all right. Version facts checked: UTF-8 names in v3.0.0, OpenMetrics federation v2.23.0, exemplars v2.26.0, holt_winters renamed, consoles unbundled in 3.0; all right.

Counts: wrong 10, unsupported 15, ambiguous 1, unclear 6, minor 47 (79 findings, 86 patches, 1 needing research).

## Systematic habits (same as the pilot, still present)

1. **Invented "why" in explanations** is still the main habit, at about half the findings: "That's why…", "exactly why…", "This is why…", "a deliberate…". Two of them are wrong: remote read's scalability limit is put down to API instability, and failed-scrape trade-offs are pinned on the wrong pattern.
2. **Dropped hedges**: "always goes up" without "unless there is a counter reset", "usually one metric" becomes "one metric", and group_by '...' loses its exceptions.
3. **Label-set claims that forget __name__**: two cards say vector/scalar arithmetic leaves labels "completely unchanged", but the metric name is dropped. The deck's own arithmetic-drops-metric-name card says so.
4. **Anchors that don't hold the claim**: NHCB is cited to the OTel section, atomic transfers to the histograms Overview, and Alerting rules text to the Alerting overview.
5. **Examples that give away later cards**: delta's temperature example and grouping's network partition. The time-since-stuck-logic pair asks the same question twice, so one is deleted.
6. **Figures built from third-party raster logos**: the official architecture SVG embeds product logos, which DIGEST rules out.

Note: the one needs-research line in the fixes file has no `field` or `value`, so apply-fixes.mjs will not touch the card.
