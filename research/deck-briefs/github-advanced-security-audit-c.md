Organisation-level rulesets: the live pages (re-fetched 2026-09-26) still contradict each other. about-rulesets says rulesets apply "to a repository or to multiple repositories in an organization for customers on GitHub Team and GitHub Enterprise plans" and allows "75 organization-wide rulesets", then says "For organizations on the GitHub Enterprise plan, you can set up rulesets at the organization level". The merge protection page says "At the organization level (GitHub Enterprise plans only)". The patches below keep cards on the parts that do not conflict. Whether GitHub Team gets organisation-level code scanning merge protection is still an open research question.
