## Traps

- [T1] Microsoft names six principles; the Azure Machine Learning page puts "Fairness and inclusiveness" under one heading. The outline tests them separately, so inclusiveness needs its own framing.
- [T1] Transparency is about people understanding how decisions are made ("interpretability"). Accountability is about humans keeping "meaningful control" and AI not being "the final authority". The two are easily swapped.
- [T1] Content filters cover four harm categories (hate, sexual, violence, self-harm) at four severity levels (safe, low, medium, high). "Safe" content is annotated but "isn't subject to filtering and isn't configurable".
- [T1] A filtered prompt fails with HTTP 400; a filtered completion returns `finish_reason` `content_filter`. If the filtering system is unavailable, the request "still completes without content filtering".
- [T1] Prompt Shields handles two attack types: user prompt attacks and indirect attacks, where instructions are embedded in content.
- [T2] Temperature ranges 0–2; higher is "more random", lower "more focused". Top_p also controls randomness: "alter one of these two parameters at a time, not both."
- [T2] Start with Global Standard, which "launches first when a new model releases, has the lowest price, and offers the broadest region coverage". Data Zone keeps processing within the US, EU or APAC. Provisioned reserves capacity; Standard is pay-per-token.
- [T2] Global Batch has a 24-hour target turnaround at 50% less cost. The Developer deployment type is for evaluating fine-tuned models only and has no SLA.
- [T2] Managed compute deploys model weights to "dedicated virtual machines", billed by VM core hours. Serverless deployments consume models as APIs "without hosting them on your subscription" and bill for inputs and outputs.
- [T3] Azure Language now splits features into "core" and "legacy". Key phrase extraction, entity linking, sentiment analysis and opinion mining, summarisation, question answering and CLU are listed as legacy; PII detection, language detection, prebuilt and custom NER and text analytics for health are core. The outline still tests key phrases, entities, sentiment and summarisation.
- [T3] NER categorises entities into predefined types; entity linking disambiguates them and "returns links to Wikipedia".
- [T3] Extractive summarisation returns salient source sentences; abstractive summarisation generates sentences that "aren't verbatim".
- [T3] Opinion mining is "aspect-based sentiment analysis", a feature of sentiment analysis, not a separate service.
- [T3] Renamed products: the docs say "Foundry Tools (formerly Azure AI Services)" and call the platform Microsoft Foundry. Learn URLs under `/azure/ai-foundry/` now redirect to `/azure/foundry/`. Older material uses the earlier names.
- [T4] Face verification is one-to-one matching; face identification is one-to-many. Face detection is "required as a first step in all the other scenarios".
- [T4] Tagging returns labels; object detection adds bounding-box coordinates.
- [T4] OCR extracts text; intelligent document processing "uses OCR as its foundational technology" to extract structure, key-values and entities.
- [T4] Azure Vision marks Image Analysis and OCR as "(legacy)". Image Analysis 4.0 is deprecated and "will be retired on September 25, 2028". Custom image classification, object detection, product recognition and background removal retired on 31 March 2025.
- [T5] A system message "influences the model, but it doesn't guarantee compliance".
- [T5] Three agent types: prompt agents (configuration only), voice-based prompt agents and hosted agents (code). An ephemeral agent built with the Responses API lives in your code, not as a Foundry resource.
- [T5] The Python quickstart installs `azure-ai-projects>=2.3.0` (the 2.x line is "Foundry (new)"; 1.x is "Foundry (classic)"). Samples use Microsoft Entra ID through `DefaultAzureCredential`. The SDK overview adds: "API keys work on `/openai/v1`."
- [T5] The project endpoint is `https://<resource-name>.services.ai.azure.com/api/projects/<project-name>`. The OpenAI SDK endpoint is `https://<resource-name>.openai.azure.com/openai/v1`. An Azure OpenAI resource provides only the latter.
- [T6] Voice agents run either native speech-to-speech (a realtime model) or a cascaded text model (speech recognition, text model, speech synthesis). The cascade gives more voice choice; native gives lower latency.
- [T6] The Realtime API connects through WebRTC, SIP or WebSocket; WebRTC is recommended for low latency.
- [T6] Text to speech is billed per character, including spaces and punctuation.
- [T7] `dall-e-3` "was retired on March 4, 2026"; use a `gpt-image-` model. Older material teaches DALL-E.
- [T7] The `detail` setting for vision input is `low`, `high` or `auto` (default `auto`). `low` processes a 512x512 version.
- [T8] Content Understanding field methods are Extract, Classify and Generate; Extract works "for documents only".
- [T8] Video analysis samples about one frame per second, so "rapid motions or single-frame events might be missed".
- [T8] `prebuilt-read` gives basic OCR "without layout analysis"; `prebuilt-layout` adds tables, sections and structure.
- **Outdated outline in circulation.** AI-900 ("Skills measured as of May 2, 2025") had five domains. These included "fundamental principles of machine learning on Azure" (regression, classification, clustering, deep learning, Azure Machine Learning), which AI-901 drops. AI-900 said "Data science and software engineering experience are not required"; AI-901 expects Python.
- **Stale text on Microsoft's own pages.** The AI-901 exam and certification pages still describe the exam with the AI-900 blurb ("fundamental principles of machine learning on Azure …"). The study guide's documentation list still links Anomaly Detector, Language Understanding and Azure Bot Service, which are not in the skills outline. The retired AI-900 exam page still shows "Retirement date: none". Trust the skills outline.
