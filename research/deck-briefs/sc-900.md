## Traps

- [T1] The customer-retained list differs by source. The SC-900 unit lists data, identities and access, endpoints, and configuration choices. The CC BY article lists four different items (the AZ-900 brief cites the article). Teach the unit's list for SC-900 and flag the difference.
- [T1] Hashing is one-way and uses no key; encryption is reversible with a key. Salting defeats precomputed (rainbow-table) attacks.
- [T1] Symmetric encryption uses one shared key and is fast, but the key is hard to distribute. Asymmetric encryption uses a public and private key pair; it solves distribution and enables digital signatures.
- [T1] Data residency is where data may be stored. Data sovereignty is that data is subject to the laws of the country or region where it sits.
- [T1] The defence-in-depth unit lists seven layers with data innermost. The Zero Trust unit lists seven pillars, with "visibility, automation, and orchestration" as the seventh.
- [T2] Authentication always comes before authorisation. An ID token proves sign-in (authentication); an access token grants access to a resource (authorisation). OpenID Connect is for authentication; OAuth 2.0 is for authorisation.
- [T2] Federation trust is not automatically bidirectional.
- [T3] Entra Connect Sync "is being replaced by Cloud Sync". The unit calls Cloud Sync the recommended tool. Older material teaches Connect.
- [T3] Identity types have multiplied. The concepts unit now names four kinds (human, device, workload, agent), and the Entra unit adds agent identities alongside workload identities. The 21 October change log marks this group "Minor", so check the unit again after that date.
- [T3] A system-assigned managed identity's service principal is tied to the lifecycle of its Azure resource; a user-assigned one is created as a standalone Azure resource.
- [T3] External guest and external member are both B2B collaboration users. B2B direct connect is a mutual trust between two Entra organisations.
- [T4] The MFA method list differs by source: the training unit lists 12 methods and the CC BY overview lists 13 (it adds QR code).
- [T4] Security questions for SSPR "will be retired" in March 2027.
- [T4] Security defaults are free; Conditional Access needs Microsoft Entra ID P1 or P2.
- [T4] Password protection combines the custom banned list with the global list. Evaluation normalises the password and fuzzy-matches with an edit distance of one.
- [T5] Microsoft Entra roles control Entra resources (users, groups, applications). Azure roles control Azure resources through Azure Resource Management. Don't confuse the two.
- [T5] Conditional Access policies are if-then statements. Block is the most restrictive decision. Session controls are a third control type, besides block and grant.
- [T6] In PIM, an eligible assignment must be activated before use, whereas an active assignment needs no action. PIM covers Entra roles, Azure roles and groups. Its audit history covers 30 days.
- [T6] Sign-in risk is the probability that an authentication request isn't the owner's; user risk is the probability that the account is compromised. Risk-based policies need P2 (licence table).
- [T7] DDoS Protection covers layers 3 and 4; layer 7 needs a WAF. It has two tiers, Network Protection and IP Protection (pay per protected IP).
- [T7] NSG rules are evaluated on five-tuple information, while Azure Firewall is "a fully stateful firewall as a service". NSG rule priorities run from 100 to 4096, and lower numbers are processed first. The default inbound rules end with DenyAllInBound at 65500.
- [T7] Bastion has four SKUs (Developer, Basic, Standard, Premium). The target VM needs no public IP, and traffic uses TLS on port 443.
- [T7] Key Vault Standard uses software keys; Premium uses HSM-protected keys.
- [T8] Foundational CSPM is free and on by default; the Defender CSPM plan (attack path analysis, cloud security explorer and more) is paid. CSPM covers posture; CWPP protects workloads.
- [T8] MCSB is the default standard in Defender for Cloud. The AZ-900 training still names "Azure Security Center" in one example; the SC-900 security-management module has a unit slug `describe-&amp;-explore-azure-security-center` in the catalog. Teach Defender for Cloud.
- [T9] SIEM collects and correlates; SOAR orchestrates and automates the response. In Sentinel, automation rules manage incidents centrally, and playbooks are Logic Apps workflows that they can trigger.
- [T9] The Azure portal experience for Sentinel retires on 31 March 2027, after which Sentinel is "available only in the Microsoft Defender portal". The trademark list still carries the old name "Azure Sentinel".
- [T10] The module slug is still `describe-threat-protection-with-microsoft-365-defender`, and older material says "Microsoft 365 Defender". The product is now Microsoft Defender XDR.
- [T10] The outline says "Microsoft Threat Intelligence". The training unit says "Microsoft Defender Threat Intelligence (Defender TI)", and the Learn page is titled "Threat intelligence in Microsoft Defender". They are the same objective, with names in flux.
- [T10] Defender for Identity watches on-premises Active Directory signals through sensors; Entra ID Protection protects cloud identities. Defender for Cloud Apps is the CASB.
- [T10] Defender Vulnerability Management now sits under Exposure management in the Defender portal (Learn page note).
- [T10] Advanced hunting covers up to 30 days of raw data.
- [T12] The compliance score starts from the Microsoft 365 data protection baseline. It counts your points and Microsoft-managed points, and actions carry different point values by risk.
- [T13] A retention policy applies at container level; a retention label applies at item level and travels with the content. An item has one retention label at a time.
- [T13] A sensitivity label is for protection and classification; a retention label is for keeping or deleting content. Both are Purview labels, so they are easily confused.
- [T13] Content explorer shows what sensitive items exist and where; activity explorer shows what users did with labelled or sensitive content.
- [T13] A regulatory record's label can't be removed, and its retention period can't be shortened.
- [T14] Audit (Standard) is on by default and keeps records for 180 days. Audit (Premium) keeps Entra ID, Exchange, OneDrive and SharePoint records for one year by default. Audit log retention policies keep records for up to one year, or up to 10 years with an add-on licence.
- [T14] Insider Risk Management (risky user activity) is not Communication Compliance (messages). Adaptive protection feeds insider risk levels (elevated, moderate, minor) into DLP, Data Lifecycle Management and Conditional Access.
- [All] Microsoft Learn is **not** available during Fundamentals exams.
- [All] Copilot and AI now run through many units (AI shared responsibility, agent identities, Copilot in Defender and Purview). The exam may test them where the objectives cover them. Treat Copilot-specific concepts as extra.
