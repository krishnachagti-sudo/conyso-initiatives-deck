## Traps

- [T1] Customer responsibilities differ by source. The training unit lists three things the customer always keeps (data, devices, accounts and identities). The CC BY shared-responsibility article lists four (data, endpoints, accounts, access management). Cite the article's list.
- [T1] Cloud spending is operational expenditure (OpEx), not capital expenditure (CapEx).
- [T1] Reservations commit to specific resources for one or three years. A savings plan commits to an hourly spend for one or three years. Spot VMs use spare capacity, can be evicted and have no SLA.
- [T1] Multicloud (several public providers) is not the same as hybrid (public plus private).
- [T2] Vertical scaling means scaling up or down (more CPU or RAM). Horizontal scaling means scaling out or in (more or fewer instances).
- [T2] Management *of* the cloud (autoscale, templates, alerts) is not management *in* the cloud (portal, CLI, APIs, PowerShell).
- [T3] IaaS is the most flexible and gives the most control. SaaS is the least flexible and the easiest to use. PaaS shares some networking and security settings.
- [T4] An availability zone is one or more datacentres within a region, not a region. The training unit says zone-enabled regions have "a minimum of three" zones. The reliability docs only say a region "might provide four".
- [T4] Region pairs: the training unit's example is "West US paired with East US". The reliability docs say "West US 3 is paired in one direction with East US" and East US is paired both ways with West US. Brazil South's pair is outside its geography. Nonpaired regions exist. The "at least 300 miles" figure appears only in the training unit.
- [T4] Resource groups can't be nested, and a resource sits in exactly one resource group. Deleting a resource group deletes everything in it.
- [T4] Management group limits: 10,000 per directory and six levels of depth. Each management group and subscription has one parent. There is a single root management group.
- [T5] Availability sets use update domains (planned maintenance) and fault domains (shared power or network). Where zones are available, zone-based designs "are often preferred".
- [T5] Container Instances is the simplest way to run a container. Container Apps adds load balancing and scaling. AKS is orchestration.
- [T5] Azure Functions is stateless by default; Durable Functions are stateful.
- [T6] There is one VPN gateway per virtual network. Route-based gateways are needed for point-to-site, VNet-to-VNet and coexistence with ExpressRoute.
- [T6] ExpressRoute doesn't cross the public internet; a VPN is encrypted over the internet. Peered VNet traffic stays on the Microsoft backbone.
- [T6] Azure DNS hosts domains but "can't" be used to buy a domain name.
- [T6] A private endpoint is a network interface with a private IP address from the VNet. A public endpoint has a public IP address. A service endpoint is a different feature.
- [T7] Minimum retention: cool 30 days, cold 90 days and archive 180 days; the cool and cold figures apply on general-purpose v2 accounts. Archive is offline, with retrieval latency of hours, and can't be the account default. Archive is supported only on LRS, GRS and RA-GRS accounts.
- [T7] The docs now also list a "Smart tier" that moves data between hot, cool and cold automatically. The training unit doesn't mention it.
- [T7] Secondary-region data can't be read unless the account uses RA-GRS or RA-GZRS, or after a failover. Geo-replication is asynchronous, so recent writes can be lost.
- [T7] GZRS uses ZRS in the primary region and LRS in the secondary region. GRS uses LRS in both.
- [T7] AzCopy sync runs one way only. Azure File Sync caches Azure Files on Windows Server, with cloud tiering.
- [T7] Storage account names are 3–24 characters, numbers and lowercase letters only, and unique across Azure.
- [T8] The training unit teaches Microsoft Entra Connect. The Entra docs say "Microsoft Entra Cloud Sync is the future of synchronization for Microsoft. It replaces Microsoft Entra Connect."
- [T8] The training unit presents External ID for customers as "formerly Azure AD B2C". The External ID overview calls Azure AD B2C "a legacy solution".
- [T8] Entra Domain Services syncs one way, from Entra ID into the managed domain. Changes made in the managed domain don't flow back.
- [T8] Authentication proves who you are; authorisation (RBAC) decides what you can do. RBAC is additive, is inherited by child scopes and is enforced through Resource Manager, not at the data level.
- [T8] The Conditional Access overview lists six signal types; the training unit names only user, location, device and application.
- [T9] The Total Cost of Ownership (TCO) calculator "has been retired". Only the pricing calculator remains in the objective, and it provisions nothing.
- [T9] A billing zone is a grouping of regions for bandwidth billing, not an availability zone. Some inbound transfers are free; outbound transfer pricing is based on billing zones.
- [T9] Tags are not inherited from a resource group or subscription. Azure Policy can apply or inherit them.
- [T10] Azure Policy controls what resources may look like; RBAC controls who can act. Locks apply "regardless of RBAC permissions".
- [T10] The lock names differ by tool. In the portal they are Delete and Read-only; on the command line they are CanNotDelete and ReadOnly. A ReadOnly lock is "similar to" limiting all authorised users to what the Reader role allows.
- [T10] The Azure Policy training unit's initiative example still names "Azure Security Center". Teach Microsoft Defender for Cloud (T8).
- [T10] Azure Blueprints (Preview) retires on 31 January 2027, with a phased retirement starting on 31 July 2026. It isn't in the AZ-900 outline.
- [T11] Azure CLI and Azure PowerShell are functionally equivalent and differ in syntax. Cloud Shell offers both, in the browser.
- [T11] ARM templates are declarative JSON; Bicep is a simpler declarative language that deploys through ARM.
- [T12] Service Health has three views that narrow from Azure status (global) to Service Health (your services) to Resource Health (a single resource). Advisor gives recommendations in five categories.
- [T12] Log Analytics is where you query the logs; Application Insights monitors applications. An alert rule sends its notifications through an action group.
- [All] Microsoft Learn is **not** available during Fundamentals exams. It is available during associate and expert exams, so advice written for those exams doesn't apply here.
