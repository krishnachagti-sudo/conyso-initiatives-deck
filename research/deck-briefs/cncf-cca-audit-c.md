# cncf-cca audit, part c (topics 8–11: 08-hubble, 09-installation, 10-cluster-mesh, 11-bgp-external)

cca.installation.scn-v-prefix | wrong | The front's command gives the version as a third positional argument (`... oci://quay.io/cilium/charts/cilium v1.20.2`). `helm install NAME CHART` rejects extra arguments ("expected at most two arguments") before it looks for a chart, so the stated "chart not found" error cannot come from this command. The docs' OCI quick-start uses the same positional form, but their other commands pass the version with `--version`. Fixed by using `--version v1.20.2`. | "helm pull oci://quay.io/cilium/charts/cilium --version <VERSION>"; "helm install cilium cilium/cilium --version 1.20.2" (k8s-install-helm, #using-oci-registries-recommended, #install-cilium); "“chart not found” Double-check your version number. Remember: no “v” prefix for Helm versions." (#chart-not-found)
cca.hubble.redaction | minor | The back says redaction "is turned on with the `--hubble-redact-enabled` option". The docs present that option together with a separate option for each redaction feature. | "Cilium provides the --hubble-redact-enabled option ... it offers the following features ... For HTTP: redacting URL query (GET) parameters (--hubble-redact-http-urlquery)" (observability/visibility, #security-implications)
cca.hubble.hubble-metrics-enable | minor | The explanation "No metrics are exported until you name the set you want" goes beyond the page, which only says to provide the set in `hubble.metrics.enabled`. | "you need to enable Hubble with hubble.enabled=true and provide a set of Hubble metrics you want to enable via hubble.metrics.enabled." (observability/metrics, #installation-with-a-static-metrics-exporter)
