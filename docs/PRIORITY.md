# Build order for the next decks

From master-list.csv, ranked by traction (demand ×3, search ×2) and by how
cleanly a deck can be sourced (source ×2, rules ×2), plus gap and partners.
Exams whose core content sits on sites we may not use are dropped or parked:
FINRA (its terms bar AI use), MSRB (no derivative works) and nasaa.org
(robots.txt blocks automated access).
